Restaurant Order System
Order management system for restaurants, allowing customers to place orders, kitchen staff to manage order status, and managers to administer the menu.

Features
Customer: Place orders through an intuitive interface
Kitchen: View orders in real-time and update status (In Progress/Done)
Manager: Add, edit and remove menu items

Technologies Used
Frontend: React + Vite
Backend: Node.js + Express
Routing: React Router DOM
Other: Body-parser for request parsing

Installation
Prerequisites

Node.js (recommended version: 16+)
npm

Steps

Clone the repository:

bashgit clone https://github.com/wom2000/portfolio/tree/main/restaurante
cd restaurante

Install frontend dependencies:
npm install

Install backend dependencies:
cd backend
npm install
cd ..

How to Run
Development

Start the backend:
cd backend
node app.js

In another terminal, start the frontend:
npm run dev

Access the application at http://localhost:5173
